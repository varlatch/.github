## Varlatch

Self-hosted secrets and environment configuration, built for AI coding agents.

Varlatch stores, authorizes, audits, and delivers the configuration your
applications need, from a developer's laptop to CI and production. Secret
values live in a dedicated daemon with envelope encryption, people sign in
with passkeys, and a coding agent can use a credential without ever being
able to read it.
